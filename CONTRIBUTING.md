# Contributing to jesusarielgb-works

This file applies to every repository of the organisation that has no CONTRIBUTING of its own.

1. Open an issue before a significant change.
2. Every rule states how it is verified, and every citation points to a verified record of the
   [engineering casebook](https://github.com/jesusarielgb-works/engineering-casebook). Never cite a source you have not read.
3. Do not move or rename a file listed in a repository's `anclas.json`; other repositories consume it.
4. Update `CHANGELOG.md` under `[Unreleased]`.
5. Contributions are released under the license of the repository they go to.
