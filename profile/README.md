# jesusarielgb-works

Open-source frameworks, standards, books and research by **Jesús Ariel González Bonilla**.

| Work | Type | Version | Description |
|------|------|---------|-------------|
| [engineering-casebook](https://github.com/jesusarielgb-works/engineering-casebook) | standards | v1.0.0 | Verified records of engineering failures and successes, and the sources behind the rules of the jesusarielgb-works frameworks |
| [liquibase-migration-standards](https://github.com/jesusarielgb-works/liquibase-migration-standards) | standards | v1.1.0 | Naming conventions, structure and rollback strategy for Liquibase migrations — MIT |
| [microservices-governance-framework](https://github.com/jesusarielgb-works/microservices-governance-framework) | framework | v1.0.0 | A complete microservices governance framework — documentation templates, ADRs, OpenAPI contracts, TDD strategy, DevOps, and stack guides. MIT Licensed. |
| [mobile-governance-framework](https://github.com/jesusarielgb-works/mobile-governance-framework) | framework | v1.1.0 | Stack-agnostic governance framework for mobile applications (MIT). Companion to monolith & microservices governance frameworks. |
| [monolith-governance-framework](https://github.com/jesusarielgb-works/monolith-governance-framework) | framework | v2.1.0 | Governance framework and standards for monolithic software systems — MIT |

Each repository states its own license. Rules in the frameworks cite the verified records of the
[engineering casebook](https://github.com/jesusarielgb-works/engineering-casebook).
